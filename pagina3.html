GitHub y trabajo en equipo

GitHub es una plataforma en la nube que aloja repositorios de Git. Además de respaldar el código, permite que varias personas colaboren en el mismo proyecto desde computadoras distintas.

Repositorios Colaboradores Historial

Para agregar a un compañero se entra a Settings, luego a Collaborators y se busca su usuario de GitHub. Esa persona recibe una invitación por correo que debe aceptar.

Cuando varias personas modifican el mismo archivo pueden aparecer conflictos. Por eso conviene hacer git pull antes de empezar a trabajar y hacer commits pequeños y frecuentes.

Usar control de versiones es una habilidad básica para cualquier ingeniero de software.
