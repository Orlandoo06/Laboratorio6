Comandos básicos de Git

Estos son los comandos que se usaron en el laboratorio para llevar los archivos de la computadora a GitHub. Se escriben en Git Bash dentro de la carpeta del repositorio.

Descarga una copia completa de un repositorio de GitHub, con todo su historial.

Agrega todos los archivos nuevos y modificados al área de preparación.

Guarda los cambios preparados como una nueva versión en el historial local.

El comando git status muestra qué archivos cambiaron, cuáles ya están preparados y cuáles todavía no se rastrean. Conviene usarlo antes y después de git add.

ComandoPara qué sirve
git statusVer el estado del repositorio
git logVer el historial de commits
git pushSubir cambios a GitHub
